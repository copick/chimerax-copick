Command: copick spotlight

Usage:
copick spotlight  [ state ]  radius r  weighted true|false  mode surface|mesh|volume|mip  features dark|light  surface_level value  image_levels v1,b1,v2,b2,...  particles true|false

The copick spotlight command shows only a sphere of tomogram data around the active particle, hiding the rest of the volume. The spotlight follows the particle stepper (aa/dd, the stepper widget, table clicks) and right-clicks on particle markers in the 3D view – enabling the spotlight automatically switches the right mouse button to the select mode. It can also be toggled with the Spotlight button in the Copick toolbar tab. Switching to any other view mode (the Slab, Volume, Orthoplanes or Surface toolbar buttons, or the qq/ee shortcuts) turns the spotlight off and returns to that view.

The optional state argument is one of:

  • on / off / toggle – enable, disable or toggle the spotlight.
  • report – log the whole-volume statistics and the auto-estimated (or user-set) render levels in a form that can be pasted back into the command to adjust them.

Without any arguments, copick spotlight logs the current configuration.

Options

  • radius – sphere radius in physical units (Å), default 500.
  • weighted – if true (default), data fades out with a gaussian weight (σ = radius/3); if false, the sphere has a hard edge.
  • mode – render mode for the spotlight volume:
    • surface – isosurface at the surface level.
    • mesh – wireframe isosurface at the surface level.
    • volume – volume (image) rendering with the image levels (default).
    • mip – maximum intensity projection with the image levels.
  • features – polarity of features in the data. CryoET tomograms are usually dark features on a bright background (default); use light for inverted data.
  • surface_level – isosurface threshold in raw tomogram units. By default it is auto-estimated from whole-volume statistics (mean − 2σ for dark features, mean + 2σ for light), so it does not change with the spotlight position. For dark features the threshold is below the volume mean; box faces are disabled so the surrounding background produces no caps.
  • image_levels – opacity ramp for volume/mip rendering as comma-separated value,brightness pairs in raw tomogram units. Default is auto-estimated: 0.9 brightness at mean − 3σ falling to zero at mean + 0.5σ (mirrored for light features). The peak is kept below full saturation so features retain interior gradation.
  • particles – if true, particles outside the sphere are hidden as well (all loaded pick lists); default false: all particles stay visible while the spotlight is on (stepping does not hide the other particles, unlike the regular slab stepping).

In volume and mip modes, features are rendered in the color opposite to the view background: white on a dark background, dark on a light background. After changing the background color, re-apply the mode (e.g. copick spotlight mode volume) to update the color. Radius, weighting, mode, features and the particles option persist across sessions; levels are re-estimated for each tomogram unless set explicitly. Use copick spotlight report to inspect the estimates.

Examples:

copick spotlight on
copick spotlight report
copick spotlight radius 300 weighted false
copick spotlight mode mip
copick spotlight surface_level -2.9 mode surface
copick spotlight image_levels -2.9,1,0.5,0 particles true
copick spotlight off

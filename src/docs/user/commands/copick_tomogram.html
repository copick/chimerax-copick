Command: copick show / close / list tomogram

Usage:
copick show tomogram [ tomo-type | next | back ] [ voxel_size size ]
copick close tomogram [ tomo-type ] [ voxel_size size ] [ others true | false ]
copick list tomograms

Several tomograms of the active run can be loaded at once, for example to compare a wbp and a denoised reconstruction or two voxel spacings. Exactly one is shown at a time; switching hides the others and carries over the camera, the slab position and orientation (in Å, so it also works across voxel spacings), the display mode (slab, orthoplanes, volume, surface), clipping and the contrast polarity. Each tomogram keeps its own contrast levels and step. Overlaying two tomograms is not supported: ChimeraX cannot render two coplanar slabs together.

In the run tree, loaded tomograms are shown in bold and the shown one has a check mark. Right-click a tomogram for Show, Unload and Unload all other tomograms. The number of tomograms kept loaded is set in the table settings (⚙); beyond it, the least recently shown tomogram is unloaded.

commandmeaning
copick show tomogram Show the tomogram of type tomo-type of the active run (largest voxel spacing unless voxel_size is given), loading it if needed. next cycles through the loaded tomograms (shortcut tt), back flips to the previously shown one (shortcut tb).
copick close tomogram Unload a loaded tomogram (default: the shown one; the previously shown one takes its place). With others true, unload all loaded tomograms except the shown one.
copick list tomograms List the loaded tomograms with their model numbers; the shown one is marked.

Examples:

copick show tomogram denoised
copick show tomogram wbp voxel_size 20
copick show tomogram back
copick close tomogram others true

See also: copick open run.

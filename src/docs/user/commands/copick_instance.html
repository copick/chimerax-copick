Command: copick instance

Usage:
copick instance edit [ copick-uri ]
copick new segmentation object-name [ userId id ] [ sessionId id ]
copick instance (paint | erase | pick | new | undo)
copick instance id N
copick instance merge ids into id
copick instance delete ids
copick instance (show | hide | isolate) ids
copick instance brush radius
copick instance save [ userId id ] [ sessionId id ]
copick colorpicks [ on | off ]
copick annotate [ show | hide | toggle ] [ page filaments | instances | picks ]
copick save

Instance segmentations hold one integer ID per voxel (0 = background); the IDs match the instance IDs of picks and filaments of the same object, and are drawn with the same colours. Panoptic segmentations (object label + instance channels) are shown with one surface per segment and can be browsed, not edited. Both appear in the Segmentations tab with their type.

Editing works on a full-resolution copy of the volume: copick instance edit loads an instance segmentation, copick new segmentation starts an empty one at the shown tomogram's voxel spacing. The right mouse button then paints the current ID as a sphere of the brush radius where the mouse meets the tomogram plane (paint copick instance); erase copick instance clears voxels and pick copick instance makes the clicked ID current. Surfaces of the IDs an edit touched are rebuilt when the mouse is released. The undo stack keeps the last 20 edits. Limits: a sphere brush only, and large volumes need memory.

ids is a list such as 3,5-8. show / hide / isolate act on the active instance or panoptic segmentation (segment indices for panoptic). copick colorpicks on colours every particle list by instance ID (filament picks always are). copick save stores all edited picks, filament sets and the edited instance segmentation that were opened from editable storage. copick annotate shows or hides the Copick Annotate window (tracing, instance editing and browsing).

Examples:

copick instance edit microtubule:tracer/1@21.6?instance=true
copick instance new
copick instance brush 75
copick instance merge 2 into 1
copick instance save sessionId manual-3

The Segmentations tab, the Copick Edit toolbar tab and the shortcuts pi ei ki ni iu run the same commands.

See also: copick filaments, copick open / show / hide.

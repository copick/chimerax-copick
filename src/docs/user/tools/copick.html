Tool: Copick

The Copick tool provides collaborative annotation of cryo-electron tomograms using the copick data model. It browses the runs of a project, loads tomograms, and shows or edits picks, meshes and segmentations, rendering them through ArtiaX.

Start the tool from the Tools → Volume Data → Copick menu, then load a project with the copick start command, or create a new one with copick new.

Storage compatibility

Copick 2.0 projects may contain OME-Zarr 0.4 / Zarr v2 images or OME-Zarr 0.5 / Zarr v3 images. Both are displayed through ChimeraX-OME-Zarr without converting the source. Newly created or rebuilt volume stores use OME-Zarr 0.5 / Zarr v3. Resolution paths, chunks, shards, key encodings and codecs are read from metadata and the store rather than assumed by this tool.

Layout

  • Gallery / Tree – browse runs. Double-clicking a tomogram opens it (see copick open run). A search box filters runs by name; the floating buttons switch between gallery, details and 3D views.
  • Picks / Meshes / Segmentations tabs – the entities available for the active run. Double-click a row to show/hide it; use the row buttons to create, duplicate or delete entities. The particle stepper navigates individual picks.
  • Edit Object Types – manage the project's pickable objects.
  • Reload – reload the project from its config file (see copick reload).

Scripting

Most UI actions have command equivalents so sessions can be scripted, and the corresponding command is echoed to the Log whenever you perform the action in the UI. See the Commands section and Copick URIs.

Toolbar

A Copick toolbar tab provides visualization (slab, volume, orthoplanes, surface), binning, marker/axis/surface visibility, viewing directions, and particle placement, manipulation and deletion. A Copick Edit tab gathers the annotation tools: the Annotate window, new picks / filaments / instance segmentations and Save All; the most used particle tools (place on the plane, select, move / rotate, delete; the same as in the Copick tab); filament tracing (trace mode, cut mode, new, previous / next, reverse, join, delete, save); instance editing (paint, erase, pick ID, new ID, undo, save); brush sizes; and colouring particle lists by instance or object.

Filaments and instances

The Filaments tab lists the run's traced filament sets; double-click to show one. Below the table, a stepper (<< k of N >>, shortcuts fp / fn) steps through the filaments of the active set and focuses the view on each. The Segmentations tab shows each segmentation's type (binary, multilabel, instance, panoptic); instance and panoptic segmentations are drawn as one surface per instance or segment. Instance IDs share one colour per ID across picks, filaments and segmentations.

Tracing, instance editing and instance browsing happen in a separate Copick Annotate window, so the copick panel keeps its width and height. It opens when you start tracing or editing, from the Annotate button of the Copick Edit toolbar, or with copick annotate. Its pages are Filaments (trace and cut modes, active filament, insert mode, save, and a filament browser: step, focus, show / hide, reverse, delete), Instances (edit, current ID, brush, background-only, save, and an instance / panoptic segment browser: step, focus, show / hide / isolate, merge, delete) and Pick instances (the instance IDs of the current particle list). The window is tabbed with the right-hand group (ArtiaX Options, Log, Models, ...) so it gets the full height. ArtiaX raises its options panel whenever the current particle list or tomogram changes; if Copick Annotate was the front tab at that moment, it raises itself back. Move it anywhere (ChimeraX remembers), float it, or use copick dock. See copick filaments and copick instance.
